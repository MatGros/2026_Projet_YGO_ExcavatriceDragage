### 3.3 Gain déduit de la trace (méthode et incertitude)

Méthode : `Gain = Δx_réel / ∫f_act·dt`, sur le seul segment dont **les deux extrémités sont des franchissements de seuil connus** : front PV (x = 5,0 m) à **18,437 s** → front Trémie (x = 0,0 m) à **26,437 s**.

- `∫(18,437→26,437) f_act dt = 90,72 Hz·s` (intégration trapézoïdale sur les 352 échantillons).
- `Gain = 5,00 / 90,72 = 0,0551 m/(Hz·s)` ; `= 4,95/90,72 = 0,0546` si la butée Trémie est à 0,05 m.
- **Contre-preuve croisée** : sur la jambe aller (11,560 → front PV descendant 14,837), `∫ = 90,47 Hz·s`. La position de départ qui rend les deux jambes cohérentes est `x0 = 5,0 − 0,0551 × 90,47 = +0,014 m`. Avec `x0 = 0,05 m` (seuil synthétique du modèle), `Gain_aller = 0,0547` → **écart 1 %** avec la jambe retour.
- **Conséquence** : le gain est **constant** à ±1 % sur 35 s ⇒ l'hypothèse `f_act ∝ vitesse chariot` tient sur cette trace, **et** la prémisse « chariot initialement juste hors zone Trémie » (`PLAN…:29`) est corroborée indépendamment.

⚠️ **Hypothèses portantes** (non prouvées, cf. `PLAN…:147-152` questions P0#2 et #5) : (a) le PDO `M3_ActualFrequencyHz` est proportionnel à la vitesse mécanique du chariot ; (b) les seuils 5,0 m / 0,0 m sont exacts ; (c) aucun glissement. Si (a) est faux, `0,0551` est un **facteur global**, pas un gain physique. La trace **ne peut pas** trancher (aucune mesure indépendante de position).
