# T262 — Registre actions : plafond AX10 automatique

| Risque | Mesure obligatoire | Statut |
|---|---|---|
| Fermeture P5 puis AX11 P1/P2 | Plafond AX10 AUTO = plafond AX11 effectif, borné P1..P2. | À implémenter |
| Perte proportionnalité maintenance | Branche SEMI_AUTO explicite ; chemin manuel conservé. | À vérifier |
| Contournement safety | Aucun clamp aval modifié ; ils gardent priorité de réduction. | À vérifier |
| Extension non maîtrisée | Aucun changement AX10→AX11, frein ou contacteur dans cette micro-phase. | À vérifier |
