# Synchronisation

1. Identifier les fichiers CODE touchés.
2. Trouver les AF/checklists correspondantes.
3. Comparer interface, comportement et mapping.
4. Proposer les écarts DOC/CODE.
5. Ne pas réécrire une spécification safety sans validation humaine.
