# Intake et refinement

Pour choisir et appeler des agents dans ce workflow, utiliser la référence commune
`TOOLS/AGENT_WORKFLOW/docs/MODEL_ROUTING.md`.

1. Enregistrer l'information brute sans l'interpréter.
2. Capturer date, source, auteur et contexte.
3. Poser les questions automatisme/IHM/safety nécessaires.
4. Séparer faits, hypothèses, inconnues et décisions.
5. Identifier les impacts DOC, CODE, IHM, tests et éventuels nouveaux FB/POU.
6. Créer ou mettre à jour une tâche `PLAN_TASK`.
7. Ne générer aucun code tant que les critères d'acceptation ne sont pas définis.
8. Pour safety : Ponytail interdit et validation humaine obligatoire.
