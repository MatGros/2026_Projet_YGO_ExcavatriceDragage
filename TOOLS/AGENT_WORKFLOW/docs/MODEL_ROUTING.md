# Routage des modèles

| Tâche | Modèle recommandé |
|---|---|
| C0/C1 simple | modèle économique ou local |
| C2 code métier | modèle code fiable |
| C3 mouvement/interlock | modèle fort + review read-only |
| C4 safety critique | modèle fort assisté + validation humaine |

OpenRouter et Ollama sont des fournisseurs optionnels. Les clés ne sont jamais stockées dans le dépôt.
