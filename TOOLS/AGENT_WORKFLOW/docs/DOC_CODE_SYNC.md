# Synchronisation DOC/CODE

Une modification de `CODE/` doit identifier la documentation métier impactée.
Une modification de sécurité ou de comportement opérateur doit déclencher une revue DOC/CODE.

Le workflow propose l'impact ; il ne réécrit pas automatiquement une spécification safety sans validation.

Format attendu dans les rapports :

```text
CODE impacté
DOC impactée
DOC à créer
Hors périmètre
```
