# CODEX_FB_BRAKE_BASELINE — chronogramme exploratoire M3

Banc de caractérisation visuelle du comportement actuel de `FB_Brake` utilisé par M3.
Ce n'est pas le CI officiel : les paramètres peuvent être modifiés pour une exploration,
sans changer la baseline `RESULTS/A_COMMUN/tests/test_fb_brake.st`.

Lancement : `tests\run.bat` ou `python tests\run.py`.
Le rapport et le chronogramme sont générés dans `reports/`.
