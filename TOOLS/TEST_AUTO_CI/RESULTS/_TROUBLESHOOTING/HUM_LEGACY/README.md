# HUM_LEGACY

Contenu historique reclassifie le 2026-09-13. Les commits disponibles
attribuent ces fichiers a Mathieu Gros, sans identifier un agent technique :
ils sont donc conserves sous `HUM_LEGACY` plutot que reassocies artificiellement
a un agent.

- `tests/` : scenarios, sources et outils de diagnostic conserves.
- `reports/` : traces de compilation, logs et rapports historiques.

Toute nouvelle investigation doit creer son propre repertoire `<AGENT_ID>/` a
la racine de `_TROUBLESHOOTING`, conformement au README parent.
