# ST2Pone

ST2Pone is a thin entrypoint hosted under the ST2PY tool so it behaves like a sub-component of the existing generator workflow.

## Usage

```bash
python TOOLS/OUTILS_ST2PY/st2pone/st2pone.py --bundle CODE/CODE_Bundle.xml --pou FB_Translation --out TOOLS/OUTILS_ST2PY/out --force --allow-safety
```
