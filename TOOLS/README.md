# Outils du projet

Chaque outil possède son propre dossier, sa documentation, ses tests et ses ressources.

## Outils

### `ST_PLCOPENXML_GENERATOR/`

Convertisseur autonome Structured Text → PLCopenXML / bundle CODESYS 3.5.

- Documentation : `TOOLS/ST_PLCOPENXML_GENERATOR/README.md`
- Tests : `TOOLS/ST_PLCOPENXML_GENERATOR/tests/`

### `AGENT_WORKFLOW/`

Workflow d'orchestration des agents, contrôles et intégrations. Il peut appeler le générateur,
mais ne contient pas son code.
