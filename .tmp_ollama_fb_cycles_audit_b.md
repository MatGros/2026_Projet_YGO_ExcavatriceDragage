## 🔍 Framework de revue séquenceur (à appliquer ligne par ligne)

### 1. Interface standard (VAR_INPUT / OUTPUT / IN_OUT)

| Check | Attendu standard | Gravité si écart |
|---|---|---|
| `VAR_INPUT` | `bEnable`, `bStart`, `bReset`, `bHoming`, `bSafeStop` | `MAJOR` si manquant |
| `VAR_OUTPUT` | `bReady`, `bRunning`, `bFault`, `bHomed`, `eState` | `MAJOR` si manquant |
| `VAR_IN_OUT` | `stAxis` (référence axe), `stParams` (structuré) | `MAJOR` si absent |
| Entrées structurées | `stParams` (DUT) plutôt que 10 scalaires | `MINOR` si scalaires éparpillés |
| Sorties impulsionnelles | `bDone` / `bPulse` sur front, pas de niveau | `MAJOR` si niveau maintenu |

### 2. Homing / Référencement

| Check | Attendu | Gravité |
|---|---|---|
| Entrée `bHoming` | Présente, front montant | `MAJOR` si absente |
| Sortie `bHomed` | Présente, passe à TRUE après homing | `MAJOR` si absente |
| État `HOMING` | Existe dans l'enum `eState` | `MAJOR` si absent |

### 3. États & Lifecycle

| Check | Attendu | Gravité |
|---|---|---|
| Enum `eState` | `IDLE`, `RUNNING`, `HOMING`, `FAULT`, `SAFE_STOP` | `MAJOR` si incomplet |
| `bReady` | TRUE uniquement en `IDLE` et sans défaut | `MAJOR` si logique incorrecte |
| `bFault` | Latched, reset sur front | `MAJOR` si non latched |

### 4. Reset / Front

| Check | Attendu | Gravité |
|---|---|---|
| `bReset` | **Front montant** uniquement, jamais niveau | `BLOCK` si niveau (cas d'arrêt) |
| Mémoire de front | Variable interne `bEdgeMem` dédiée | `MINOR` si absente |

### 5. Safe Stop

| Check | Attendu | Gravité |
|---|---|---|
| `bSafeStop` | Présent, état `SAFE_STOP` géré | `BLOCK` si absent (cas d'arrêt) |
| Redémarrage auto | Interdit après défaut | `BLOCK` si présent |

### 6. Variables internes & Nommage

| Check | Attendu | Gravité |
|---|---|---|
| Préfixes | `b` (BOOL), `e` (ENUM), `st` (STRUCT), `i` (INT), `t` (TIME), `fb` (FB) | `MAJOR` si non respecté |
| Variables internes | `eState`, `tTimer`, `iStep`, `bEdgeMem` | `MINOR` si manquantes |

### 7. Interdits absolus (cas d'arrêt)

- `CoupeEnable` ou `FB_Watchdog` applicatif réintroduits → `BLOCK`
- `Reset` sur niveau → `BLOCK`
- `SafeStop`/`StartStop` sur un FB non-mouvement → `BLOCK`
