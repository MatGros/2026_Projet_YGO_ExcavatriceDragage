# TwinBench — atelier OpenModelica

Le socle utilisateur est **OpenModelica / OMEdit Windows**.

## Démarrer

Double-cliquer `Lancer_TwinBench.bat`. OMEdit ouvre directement :

`modelica_atelier/Dredge.mo`

Le dossier actif contient uniquement le modèle, son lanceur OMEdit et son guide.

## Premier test

Dans OMEdit, ouvrir :

`Dredge > Examples > AnimatedGrabClosureThenHoist`

Puis choisir **Simuler avec animation**. Pour les chronogrammes, simuler
`Dredge.Examples.GrabClosureThenHoist` et tracer les variables indiquées dans le guide.

Les anciens POC et outils intermédiaires sont archivés sous
`ARCHIVES/Tools/TWINBENCH/modelica_atelier_pre_T314_20260917/` et ne sont plus actifs.

⚠️ Banc hors ligne uniquement : aucune connexion PLC et aucune commande de sortie physique.
