# Archive TwinBench avant T401

Date d'archivage : 2026-09-27  
Origine : `TOOLS/TWINBENCH/`

Cette archive conserve intégralement l'ancien TwinBench comme exemple historique :

- moteur Python et modèle YAML ;
- interface et résultats HTML ;
- traces JSON ;
- atelier OpenModelica `Dredge.mo` ;
- anciens lanceurs et documentation.

Raison : repartir sur le POC minimal T401 sans mélanger plusieurs moteurs, interfaces ou modèles.

Cette archive n'est plus une source active et ne doit pas être utilisée pour contourner le POC,
les contrats de tâches ou la frontière de sûreté PLC. Aucun fichier n'a été supprimé lors du
déplacement.
